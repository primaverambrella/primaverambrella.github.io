FAQ

Before you try it.

Is it really editable, or a picture in disguise?

Really editable. Text is text, shapes are shapes, Auto Layout is Auto Layout. When something can't be rebuilt exactly — a mask, a picture fill, a rare chart type — Slideport keeps it as a picture and tells you in the report.

Do my files leave my computer?

No. Files you drop are converted inside the plugin. Only URL imports go through our proxy, which fetches the page and its images. Full details in the privacy policy.

What about fonts?

Before import you see every font in the file and can pick a replacement. For PowerPoint, Google Fonts are embedded in the .pptx; for websites, fonts can be packed as files.

Does it use AI?

No. The conversion is deterministic — the same file gives the same result every time. It does import pages that were generated by AI tools.

Does it work in Figma Slides and FigJam?

Yes. In Figma Slides every imported page becomes a slide; slides export in presentation order.

How do I cancel?

Any time, in your lava.top account. If Pro isn't for you within 14 days, write to us for a refund.
