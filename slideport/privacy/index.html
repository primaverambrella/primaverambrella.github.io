Slideport privacy policy

Short version: your designs and files stay with you. The plugin sends a page address only when you import by URL, and anonymous usage events you can turn off.

Last updated: October 27, 2026

Who we are

Slideport is a Figma plugin made by Primavera Studio, an independent developer. In this policy “we” means Primavera Studio. Questions: open an issue or write to .

What stays on your computer

  • Your Figma document. The plugin reads selected frames only to build an export file, and that file is created on your computer. Nothing from your Figma file is uploaded to us or anyone else.
  • Files you drop into the plugin: HTML, ZIP, MHTML, EML, PowerPoint and PDF. They are parsed inside the plugin window and never uploaded.
  • Your settings: language, defaults, font substitutions, proxy address. They are stored in Figma's plugin storage on your device.

Importing by URL

When you paste a web address and click Load, the address is sent to the Slideport proxy, a small service on Cloudflare Workers. The proxy downloads that public page, its images, fonts and stylesheets, and passes them back to the plugin. Sites built with JavaScript frameworks are opened in a headless browser on Cloudflare first.

  • The proxy does not store the pages it fetches and keeps no logs of addresses in its own code. Responses may stay in Cloudflare's cache for up to 5 minutes.
  • Cloudflare, as the hosting provider, processes requests under its own privacy policy.
  • You can set your own proxy in Settings → Proxy for URLs; then requests never reach ours.
  • If you don't import by URL, the proxy is never contacted.

Anonymous usage statistics

To find bugs and see which features are used, the plugin sends anonymous events to PostHog (US region):

  • the plugin opened, which screen was shown, which button was clicked;
  • for imports and exports: file type and size, number of layers or slides, time taken, export mode, number of missing fonts;
  • error messages, so we can fix them.

Events carry a random installation ID stored in Figma's plugin storage. They contain no design content, texts, file names, page addresses, Figma user names or emails.

Turn it off: Settings → Anonymous statistics. After that no events are sent.

Feedback form

If you send feedback from the plugin settings, your message and the optional email you type go to the same PostHog project so we can read and answer it. Leave the email empty to stay anonymous.

Payments

Pro is sold through Paddle.com, our Merchant of Record. Paddle collects your payment and billing details under its own privacy policy; we never see your card. From Paddle we receive your email, country, plan and subscription status, so we can turn on Pro and answer billing questions.

When you enter your email in Settings → Slideport Pro, the plugin sends it to the Slideport server on Cloudflare, which asks Paddle whether that email has an active subscription. The server keeps no copy of the email; the plugin stores it on your device to re-check the subscription every few days.

Children, changes, contact

Slideport is a professional design tool and is not aimed at children. If this policy changes, the date at the top changes too. Questions or requests to delete feedback you sent: open an issue or email .
