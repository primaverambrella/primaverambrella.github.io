Getting started

  1. Open Slideport on Figma Community and click Open in… or Try it out.
  2. In any Figma Design, Figma Slides or FigJam file run it from Plugins → Slideport (or ⌘ / and type “Slideport”).
  3. The window has two tabs: Import and Export. The gear opens Settings, the flag switches the interface language (10 languages).

After you drop a file, an Import settings sheet appears with options for that file type only. Tick Don't show again to import straight away with your defaults. Bring the sheet back with the Import settings link under the file, or hold ⌥ while clicking Import.

Update an import in place

Every import remembers where it came from. Select an imported frame (or any layer inside it) and the Import tab shows Update “…” in place:

  • From a file: drop the new version of the same file. The button turns into Update in place.
  • Anything else: tick Replace the selected import with any new file.

The new frames take the old ones’ place, layer order and names; speaker-note stickies move with their slides. Press ⌘Z to get the previous version back.

PowerPoint import

Drop a .pptx or .potx. Every slide becomes a frame and the slides line up in a row. Drop several files at once to import them one after another. Everything is parsed inside the plugin; the file is not uploaded.

  • Text boxes become text layers with font, size, bold, color, line height, bullets and numbering. Styles are inherited from layouts and masters.
  • Shapes become rectangles and ellipses with radius, fill, gradient, stroke and shadow. Arrows, stars and custom outlines become vectors.
  • Pictures stay separate layers with cropping: PNG, JPEG, GIF, SVG.
  • Groups become frames, tables become a grid of cells with text.
  • Bar, column, line, area, pie and doughnut charts become editable shapes with axes, labels and the series colors.
  • Slide backgrounds, master and layout decorations, theme colors and fonts.
  • Speaker notes and comments, including threaded replies, become stickies to the right of the slide: yellow for notes, blue for comments.

SmartArt, OLE objects, other chart types and EMF, WMF or TIFF pictures come in as grey placeholders, and the plugin lists them after import. Flipped shapes come in without the flip.

Word import

Drop a .docx. Every page becomes a frame with the page size and margins from the file: page breaks start a new frame, and a page with more text grows downwards. The file is parsed inside the plugin and not uploaded.

  • Headings and paragraphs keep their styles: font, size, weight, color, spacing, alignment.
  • Bulleted and numbered lists, links, pictures and tables come across editable.

PDF import

Drop a .pdf. The card shows the page count and size. In the settings sheet you tick pages on thumbnails (or type 1-3, 5), choose a row, column or grid layout, and how vector graphics come in. Every page becomes a frame at 1 pt = 1 px, so a PDF exported from Figma comes back at its original size. The file is parsed inside the plugin and not uploaded.

  • Lines of text are joined into paragraphs, keeping font, weight, italic, size, color and line height for each run. Rotated text stays rotated.
  • Pictures are separate layers; rectangular crops are kept.
  • Plates, rounded rectangles, ellipses and linear gradients become Figma shapes.
  • Other vector graphics come in as paths, grouped by area, or as a backdrop: one 2× picture under the text, for maps and charts with thousands of lines.

Scanned pages come in as pictures. Password-protected PDFs don't open. Because text in a PDF is only lines, columns or table cells set very close together may merge into one layer.

Import as a design system

Turn on Import as a design system in the import settings. After the import the plugin:

  • creates color and text styles and variables for colors, spacing and radii found in the source, PowerPoint theme included;
  • links every imported layer to them, so changing one color changes the whole deck;
  • adds a style guide frame with swatches and type samples next to the import.

Available in Figma Design files.

Figma Slides and FigJam

Slideport runs in Figma Slides and FigJam too. In Figma Slides every PowerPoint slide or PDF page becomes a slide in the deck, and export follows the slide grid order. In FigJam imports come in as frames.

Export to PowerPoint

  1. Select one or more frames. Each frame becomes a slide; the slide size follows the first frame.
  2. Open the Export tab and pick a mode.
  3. Click Download .pptx.
ModeWhat you get
EditablePlates as shapes, texts as text boxes, pictures as pictures. Everything is editable.
Exact + textEach slide is an exact picture with text boxes on top. Pixel-perfect, text stays editable.
ImagesEach slide is one picture.

Slides follow the order of frames on the canvas, by rows, left to right; drag the thumbnails to change it. A file name template like {name} · {date} names the download. Before export you see thumbnails and counts of texts, shapes and pictures. After export a report shows what stayed editable, what became a picture and why, and which fonts are needed.

In PowerPoint

  • Plates are Rounded Rectangle shapes; change the radius with the yellow handle. Fill, gradient, stroke and shadow are normal shape properties.
  • Text boxes keep font, size, bold, italic, color, line height and letter spacing for each run.
  • Pictures keep cropping and radius; rotated pictures stay rotated.
  • Icons and vectors become native PowerPoint shapes you can recolor; complex ones fall back to SVG pictures.
  • The deck theme takes your brand colors and heading and body fonts, so new slides added in PowerPoint match. Optionally a palette slide is added at the end.
  • Nested frames become groups. Tables from Figma Slides and FigJam become real PowerPoint tables.

What PowerPoint can't do is simplified: of several shadows the strongest is kept, and different corner radii become equal, except top-only and bottom-only. Photos over 300 KB without transparency are re-encoded as JPEG when Compress images is on. Fonts must be installed on the computer where the deck is opened.

For Google Slides

Tick For Google Slides before downloading. Google Slides ignores embedded fonts and knows only Google Fonts and a few system fonts, so Slideport keeps those and replaces the rest with the closest Google Font — Helvetica becomes Arial, SF Pro becomes Inter, serif fonts become Noto Serif, monospaced ones Roboto Mono. The report lists every replacement. Then open Google Slides → Open file picker → Upload and choose the file.

Export to PDF

Next to Download .pptx is PDF. Every selected frame becomes a vector page made by Figma, and all pages are merged into one PDF. Text stays selectable and searchable.

Settings

  • Language: English, Español, Português, Deutsch, Français, Italiano, 日本語, 한국어, 中文, Русский.
  • Badge: a small “your file is ready” label inside the first imported frame. Turn it off here.
  • Import and export defaults: the options the settings sheet starts with.
  • Font substitution: when a font is installed under a different name than in the file, for example Alfa → Alfa Interface Sans. Separate several with ;. The plugin remembers it.
  • Anonymous statistics: on by default, turn off any time. See Privacy.
  • Send feedback: a short form; add an email if you want a reply.

Limits

  • Rotation is kept for pictures, icons and single texts, not for rotated blocks with content.
  • If a font is missing in Figma, the closest one is used (usually Inter) and the plugin names the replaced fonts.
  • In .pptx: SmartArt, rare chart types and EMF/WMF pictures are placeholders. In PDF: scans are pictures, close columns may merge.

Privacy

  • Conversion runs inside the plugin. Nothing from your Figma file is uploaded anywhere.
  • PowerPoint, Word and PDF files you drop never leave your computer.
  • Anonymous usage statistics help fix bugs. No design content or texts are included. Turn them off in Settings.

FAQ

Why are some texts in Inter after import?

The font isn't available in Figma under that name. Install it, or add a substitution in Settings → Font substitution.

The fonts look different in PowerPoint.

PowerPoint uses fonts installed on the computer where the deck is opened. The export report lists the fonts your slides need.

Does the free plan reset?

Yes, on the first day of every calendar month.
